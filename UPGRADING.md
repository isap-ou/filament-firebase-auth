# Upgrading

This file tells you how to upgrade from one plugin major version to the next.

The plugin major version equals the Filament major version.
You upgrade the plugin major when you upgrade Filament to its next major.
Minor and patch releases inside one major do not need an upgrade guide.

## To 5.0 (Filament 5)

`v5.0.0` is the first release. It requires `filament/filament: ^5.0`.
There is no earlier version, so there are no upgrade steps.
